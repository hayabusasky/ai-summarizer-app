# ai-summarizer-app

経済ニュースを自動収集 → AIで「金を持っておきたくなる」切り口の短文に要約 → X/Threadsへ自動投稿するパイプラインです。
DM対応・購入手続き・発送は意図的に自動化していません(下記「運用フロー」参照)。

## 全体像

```
RSS収集 → AI要約(該当ニュースのみ抽出) → X/Threads自動投稿
                                                ↓
                                           DMで問い合わせ
                                                ↓
                                     人が対応(解説 or 振込案内→代理購入→発送)
```

## セットアップ

```bash
npm install
cp .env.example .env   # 値を埋める
npm run dry-run        # 実際には投稿せず、生成される文面を確認
npm start               # 実際に投稿する
```

### 必要な認証情報

| 変数 | 用途 | 取得元 |
|---|---|---|
| `ANTHROPIC_API_KEY` | ニュース要約・分類 | console.anthropic.com |
| `X_API_KEY` / `X_API_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_SECRET` | X(Twitter)への投稿 | X Developer Portal(投稿には有料APIプランが必要) |
| `THREADS_USER_ID` / `THREADS_ACCESS_TOKEN` | Threadsへの投稿 | Meta for Developers(Threads API) |

`POST_TARGETS` は `x` / `threads` / `both` から選択できます。

## GitHub Actionsでの自動実行

`.github/workflows/post.yml` が1日2回(JST 8時・18時)自動実行します。リポジトリの **Settings → Secrets and variables → Actions** に上記の認証情報をSecretsとして登録してください。投稿済み記事の重複防止用データ(`data/posted.json`)はワークフローが自動でコミットし直します。

## チビボスのリール動画(Instagram・確認してから投稿)

キャラクター「チビボス」が話す縦型リール動画を毎日1本自動で作り、**あなたが確認してOKを出したものだけ**をInstagramリールに投稿します。

```
Claude Code が台本を書いて reel/queue/ に置く(背景画像の指示つき)
                ↓
Codex が背景画像を作って reel/backgrounds/ に置く
                ↓
毎日12時(JST) reel-generate.yml
  reel/queue/ から背景画像が揃った台本を1本取り出す(使った台本は reel/done/ へ) → 動画をレンダリング
  → 確認用のIssueを作成(ラベル: reel)
                ↓
あなたが確認: Actionsの「reel-preview」で動画を見る/必要ならIssue本文を編集
                ↓
ラベル「reel-approved」を付ける → reel-publish.yml が動画を作り直してInstagramに投稿 → Issueを閉じる
```

- 動画の第一声は「よう、ボスだ。」で固定です。リールではDMへの誘導はしません(キャプションには免責文だけが付きます)。
- 背景画像が揃っていない台本は飛ばされます。Codexに「AGENTS.mdの手順でリールの背景画像を作って」と頼んでください。どうしても画像なしで出したい日は、Variable `REEL_ALLOW_NO_BG=true` でグラデーション背景のまま動画にできます。
- 台本のストックが切れると、その日は何も作られません。Claude Codeに「リール台本を〇本書いて」「このニュースでリール台本を書いて」と頼んで補充してください。
- 台本をClaude APIで自動作成したい場合は、Variable `REEL_API_FALLBACK=true` と Secret `ANTHROPIC_API_KEY` を設定すると、ストック切れのときだけAPIで作成します(既定はオフ)。
- 承認ラベルが効くのは**リポジトリのオーナー本人が付けたときだけ**です。
- 投稿したくない場合は、Issueをそのまま閉じればOKです。
- 「お金の教え」の引用と出典は `src/reel/teachings.ts` で固定しています(Claudeに出典を作らせないため)。追加するときは出典を確認してから書いてください。
- 動画の見た目やポーズは `reel/README.md` を参照してください。

### 追加で必要な設定

| 種類 | 名前 | 内容 |
|---|---|---|
| Secret | `IG_USER_ID` | InstagramビジネスアカウントのID |
| Secret | `IG_ACCESS_TOKEN` | `instagram_content_publish` 権限付きの長期アクセストークン |
| Variable(任意) | `IG_GRAPH_HOST` | Instagramログインで取ったトークンなら `graph.instagram.com`(既定は `graph.facebook.com`) |
| Variable(任意) | `REEL_DRY_RUN` | `true` にすると承認しても実際には投稿しない(テスト用) |

Instagram APIへの接続はこの開発環境から確認できていません。最初は `REEL_DRY_RUN=true` で流れを確認し、その後1本だけ本番投稿して動作を確かめてください。

## ニュースソースの設定

`src/config.ts` の `FEED_SOURCES` にRSSフィードを追加・削除できます。初期値はいくつかの一般的な経済ニュースRSSを設定していますが、**このプロジェクトの開発環境からは外部ネットワークに接続できず疎通確認ができていません**。本番投入前に一度動作確認をお願いします。

取り上げる切り口は5パターンに固定しています(`src/summarize.ts` のプロンプト内):
1. 金価格の最高値更新・急騰
2. インフレ・実質金利の低下
3. 円安・ドル安などの通貨リスク
4. 地政学リスク・有事
5. 中央銀行による金購入動向

これ以外のニュースはAIが自動的にスキップします。

## コンプライアンス上の注意(重要)

- 生成される投稿文には「今買うべき」等の断定的な投資助言・価格予測を含めないようプロンプトで制限し、末尾に自動で免責文を付与しています。運用前に実際の生成文をレビューしてください。
- **特定商取引法**: SNS/DM経由の販売も通信販売に該当します。事業者名・住所・連絡先等の表示義務を満たしているか確認してください。
- **犯罪収益移転防止法**: 貴金属売買業者は特定事業者に該当し、一定額を超える取引には本人確認・記録保存義務があります。DMでの取引フローに本人確認の手順を組み込むかどうか、専門家(行政書士等)に確認することを推奨します。

このリポジトリのコードはこれらの義務そのものを充足するものではありません。あくまで集客(発信)部分の自動化ツールです。

## 運用フロー(人による対応・手動)

SNS投稿を見た読者からDMが来た場合の一次対応テンプレート例:

**トリアージ**
> お問い合わせありがとうございます。①今回のニュースについてもう少し詳しく知りたい、②実際に購入を検討したい、のどちらに近いですか?

**① 解説希望 →** 面談日程の案内へ

**② 購入希望 →**
> ありがとうございます。お手続きの流れは以下の通りです。
> 1. お振込先のご案内
> 2. ご入金確認後、代理で購入いたします
> 3. お届け先ご住所をお伺いします
> 4. 発送
>
> つきましては、まずお届け先ご住所とご希望の数量をお知らせください。

住所等の個人情報は取扱いに注意し、必要最小限の保存・適切な廃棄を行ってください。
