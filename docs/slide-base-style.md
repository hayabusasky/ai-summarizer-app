# スライド「基本スタイル」

「基本スタイルでスライドを作って」と頼まれたときは、このスタイルで作る。
元になったサンプル: https://claude.ai/artifact/XYJtptbZ5ax12aq6nhAyAG （スライド自動作成ツール構想）

## カラー

| 役割 | 色 | 用途 |
|---|---|---|
| ダーク | `#1B2433` | 表紙・締めの背景、見出し文字、表のヘッダー |
| ライト | `#F7F6F2` | 本文スライドの背景（基本） |
| ライト2 | `#ECEAE3` | 本文スライドの背景（交互に使う2色目） |
| カード | `#FFFFFF` | カードの背景 |
| アクセント | `#E8743B` | 強調スライドの背景、カードの上線・左線、矢印、ダーク背景上の番号 |
| アクセント文字 | `#B4531F` | 明るい背景上の英字ラベル・番号（コントラスト確保のため濃いオレンジ） |
| 本文グレー | `#4A5568` | 明るい背景上の本文 |
| 補助グレー | `#6A7280` | ページ番号・注記 |
| ダーク上の本文 | `#C9CFD8` | ダーク背景上の本文 |
| ダーク上の注記 | `#8E98A8` | ダーク背景上のページ番号・注記 |
| 罫線 | `#D8D5CC` / ダーク上は `#3A4558` | 表の枠、区切り線 |

背景は「ライト」と「ライト2」を交互に使い、表紙と最後のスライドはダーク、コンセプトなど一言で伝えるスライドはアクセント背景にする。

## フォント

- 日本語（見出し・本文）: **Noto Sans JP**（400 / 500 / 700）
- 数字・英字ラベル: **DM Sans**（700）
- Google Fonts: `https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;500;700&display=swap` と `https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&display=swap`

## 文字サイズ（1920×1080 キャンバス）

| 要素 | サイズ | 太さ |
|---|---|---|
| 表紙・強調スライドの大見出し | 96px | 700 |
| スライド見出し（h2） | 64px | 700 |
| カード見出し（h3）・大きめ本文 | 40px | 700 |
| 本文 | 30px（狭いカードは 26px） | 400 |
| 英字ラベル・ページ番号・注記 | 24px | ラベルは 700・字間 4px |

## レイアウトの型

- 余白: `padding:128px 128px 160px`。ページ番号は左下 `left:128px; bottom:64px` に 24px で固定
- 見出しブロック: 上に英字ラベル（例「01　課題」、DM Sans 24px、`#B4531F`、字間 4px）、その下に h2。見出しは毎回同じ位置（上端）に置く
- カード: 白背景、角丸 16px、パディング 40〜56px。上線 `border-top:8px solid #E8743B`（横並び）または左線 `border-left:8px solid #E8743B`（2列比較）
- アイコン: カード上部に 64px、色 `#B4531F`
- 手順: 番号付きカードを横並びにし、間をオレンジの矢印でつなぐ。最後のステップだけダーク背景
- 比較: 表を使う。ヘッダー行はダーク背景・ライト文字、本文行は白と `#F1EFE8` の縞。表の下に「→ 推奨：」の一文
- 表紙・締め: ダーク背景、左端に幅 24px のオレンジの縦帯
- 締めのリスト: 大きなオレンジ番号（DM Sans 64px）＋ 40px の文、行間に `#3A4558` の罫線

## 書き方のルール

- 1スライド1メッセージ。見出しは言い切りの文にする（例「MVPは『テキストからPPTXまで』に絞る」）
- 箇条書きより、カード・表・手順図・大きな番号を優先する
- 数字・名前・日付が与えられていないときは作らず、`[__週間]` や `[発表者名]` のような空欄にして返答で伝える
