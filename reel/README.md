# キャラクター付きリール動画の作成

台本(JSON)を書くと、キャラクターがセリフに合わせてポーズを変える縦型リール動画(1080×1920 MP4)ができます。

## 使い方

```bash
python3 reel/make_reel.py reel/scripts/talmud_money.json out/talmud_money.mp4
```

必要なもの: Python 3 と Pillow(`pip install pillow`)、ffmpeg、日本語フォント(IPAゴシック: `/usr/share/fonts/opentype/ipafont-gothic/ipag.ttf`)。
出力先の `out/` はgit管理外です。

毎日の自動投稿用の台本は `reel/queue/` に置きます(形式は同じで、`title` と `caption` が加わります)。ルールはリポジトリ直下の `AGENTS.md` の「リール台本を書くとき」を参照してください。

## 画面構成

```
┌──────────────┐
│   見出し(headline)   │  ← シーンごとの大きな文字。*囲み* は金色
│   出典(note)          │
│ ┌──────────┐ │
│ │ セリフ(text) │ │  ← 吹き出し。1行ずつ切り替わる
│ └────▽─────┘ │
│     キャラクター      │  ← セリフごとにポーズが変わり、話している間は軽く揺れる
│  免責文(footer)       │
└──────────────┘
```

## 台本JSONの書き方

```json
{
  "footer": "※本動画は解説であり、投資助言ではありません。",
  "bgm": "music/bgm.mp3",
  "scenes": [
    {
      "image": "images/gold.png",
      "headline": ["財産は", "*三つに分けよ*"],
      "note": "出典：タルムード（バヴァ・メツィア 42a）",
      "lines": [
        { "text": "まずはこれ。\n「財産は三つに分けよ」", "pose": "point", "secs": 3.0 }
      ]
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `footer` | | 全シーンの最下部に出す文。免責文に使う |
| `bgm` | | BGMの音声ファイル(台本JSONからの相対パス)。省略すると無音 |
| `scenes[].image` | | 背景画像(台本JSONからの相対パス、またはリポジトリ直下からの相対パス)。省略・未作成なら金色のグラデーション背景 |
| `scenes[].image_prompt` | | 背景画像の指示(Codexが画像を作るときに使う。レンダラーは使わない) |
| `scenes[].headline` | | 見出しの行のリスト。`*〜*` で囲んだ部分が金色になる |
| `scenes[].note` | | 見出しの下に出す小さな注記(出典など) |
| `scenes[].lines[]` | ○ | セリフ。`text`(`\n` で改行)、`pose`、`secs`(表示秒数) |

シーンの長さは、そのシーンのセリフの秒数の合計です。シーン同士は0.5秒のフェードでつながります。

## ポーズ一覧

`reel/character/sheet.webp` を `reel/character/poses.json` の座標で切り出しています。

| 名前 | 様子 |
|---|---|
| `smile` | にっこり、PCに向かう |
| `explain` | 手を差し出して説明 |
| `think` | あごに手を当てて考える |
| `shrug` | 両手を広げる |
| `point` | 人差し指を立てる(ポイント提示) |
| `talk` | 手を振りながら話す |
| `smug` | 腕を組んでニヤリ |
| `explain2` | 手を差し出して説明(別角度) |
| `hand_chest` | 胸に手を当てる |
| `talk2` | 手を振りながら話す(別角度) |
| `hands_clasped` | 手を組む |
| `explain3` | 手を差し出して説明(別角度) |

シート4段目は画像の下端で切れているため使っていません。キャラ画像を差し替えるときは、`poses.json` の `columns` / `rows`(切り出し位置のピクセル座標)と `names` を合わせて直してください。

## 注意

- 投資の断定的な助言や価格予測は台本に書かないでください(`footer` の免責文も残す)。
- 「ユダヤ人は〜」のように民族とお金を結びつける表現は避け、出典のある教えとして紹介してください。
